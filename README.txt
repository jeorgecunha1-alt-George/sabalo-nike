# Sabalo Sneakers
Site simples de venda de tênis criado por Dev Sabalo.

## Como usar
1. Extrai o ZIP
2. Abre o ficheiro `index.html` no browser (Chrome, Firefox, Edge...)
3. Pronto! O site funciona offline.

## Estrutura
- `index.html` → Página principal
- `css/style.css` → Estilos
- `js/script.js` → Funcionalidades (carrinho)
- `images/` → Fotos dos tênis

## Funcionalidades
- Listagem de produtos
- Adicionar / remover do carrinho
- Carrinho guardado no browser (localStorage)
- Design moderno e responsivo

Podes editar os preços, nomes e adicionar mais produtos facilmente no ficheiro `js/script.js`.
